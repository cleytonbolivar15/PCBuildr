# PCBuildr Screenshots

This directory contains screenshots for the PCBuildr GitHub repository.

## Files

- **main.png** - Main application window with PC builder interface
- **builder.png** - Component selection and PC building screen
- **analysis.png** - Build analysis with compatibility checks and scoring
- **recommendations.png** - Smart PC build recommendations interface

## Adding Screenshots

To add screenshots:
1. Take a screenshot of the PCBuildr application
2. Save as PNG format (recommended size: 1280x720 or similar aspect ratio)
3. Place in this directory
4. Reference in README.md using the format: `![Description](screenshots/filename.png)`

## Guidelines

- Use clear, well-lit screenshots
- Show key features of the application
- Include user interface, not just backend
- Avoid sensitive user data in screenshots
